## Overview

Bow Pang is a fully responsive website built with Webflow and exported as a static website. The project includes all required HTML pages, CSS styling, JavaScript interactions, images, and assets.

## Features

- Responsive design for desktop, tablet, and mobile
- Modern Webflow-based UI
- Custom animations and interactions
- Product pages and informational pages
- Optimized images and assets
- Clean HTML, CSS, and JavaScript structure

## Technologies

- HTML5
- CSS3
- JavaScript
- Webflow Export

## Project Structure
Bow-Pang/
│
├── *.html # Website pages
├── css/ # Stylesheets

└── fonts/ # Custom foNTS


## Run Locally

1. Download or extract the project files.
2. Open `index.html` in your browser.

For better development experience:

- Open the project in VS Code
- Install Live Server extension
- Run `index.html` using Live Server

## Deployment

The website can be deployed on:

- Netlify
- Vercel
- GitHub Pages
- Hostinger
- cPanel Hosting

Simply upload all files while keeping the original folder structure.

## Customization

- Edit HTML files to update page content.
- Edit CSS files to modify design and styling.
- Replace images inside the assets folder to update visuals.

## Notes

This is a static Webflow export. Webflow CMS, forms, and dynamic features may require additional configuration after deployment.
